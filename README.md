# PokeDex Web Application

A modern, responsive Pokémon directory built using HTML, CSS, and JavaScript, powered by the PokéAPI.

![PokeDex Screenshot](https://raw.githubusercontent.com/PokeAPI/media/master/logo/pokeapi_256.png)

## Features

- **Real-time Pokemon Search**
  - Search suggestions with debouncing
  - Visual feedback for no results
  - Shows Pokemon sprite in suggestions

- **Advanced Filtering**
  - Filter by Pokemon type
  - Sort by ID or name
  - Combination of filters possible

- **Detailed Pokemon Information**
  - High-quality Pokemon images
  - Base stats with visual bars
  - Type information with color coding
  - Height and weight details
  - Abilities list

- **Responsive Design**
  - Works on mobile devices
  - Responsive grid layout
  - Smooth animations
  - User-friendly interface

- **Interactive Features**
  - Click on cards for detailed view
  - Modal window for Pokemon details
  - Load more Pokemon functionality
  - Home page reset via logo

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- [PokéAPI](https://pokeapi.co/)
- Font Awesome Icons

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/RAHULRATHOD26/PokeDex-FrontEnd.git
   ```

2. Open `index.html` in your web browser

3. Start exploring Pokemon!

## Usage

- **Search**: Use the search bar to find specific Pokemon by name or ID
- **Filter**: Select Pokemon type from the dropdown to filter
- **Sort**: Choose to sort by ID or name
- **Details**: Click on any Pokemon card to see detailed information
- **Load More**: Click the "Load More" button to see additional Pokemon
- **Home**: Click the PokéAPI logo to reset all filters and return to home
